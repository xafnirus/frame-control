Privacy

Short version: the released app sends usage statistics after a first-run notice. You can turn them off. Website feedback becomes public on GitHub.

App usage statistics

Released desktop builds send anonymous usage statistics to PostHog's US cloud by default after the first-run notice has been shown. Events include a random persistent installation ID, app version, operating system, CPU architecture and Python version; app opens, updates, tabs used, headset SteamOS builds and install outcomes. Public catalogue installs may include a Steam app ID, Flathub ID or F-Droid package name. Frame Control installation, update and daily-open events may include a country code derived from your computer's time zone; the time zone itself is not sent. A headset connection may include a shortened SHA-256 hash of its machine ID, computed on the headset, plus the number of saved headsets. The original machine ID stays on the headset.

Usage events exclude local filenames, paths and account data. Person profiles and location lookup are disabled, and events use a placeholder IP address; the receiving service still handles the network connection. Turn statistics off in Privacy & updates. Show what's been sent shows recent sent events. Turning a level off removes its unsent events, not events already received.

Optional reports and contact details

Compatibility sharing and detailed error reports are off by default. Enabling compatibility sharing also sends earlier reports from this computer. Error details include scrubbed messages and tracebacks. Review free text before sharing: automatic scrubbing cannot guarantee that every personal detail is removed.

Report a problem deliberately sends a private report to the maintainer's PostHog project, independently of usage-statistics settings. Diagnostics are included by default; recent activity and server logs are optional. A contact email and permission for follow-up questions are optional. Contact email lets you save, change or withdraw permission for follow-up questions and update notices. Changes saved offline wait until PostHog is reachable. Withdrawal removes the local address and excludes it from the maintainer's current contact list; earlier events remain until retention or separate deletion. These controls record consent; they do not establish that update emails are being delivered.

See the v0.4.62 privacy guide for fields, retention and controls. Source checkouts do not send automatic telemetry by default. DO_NOT_TRACK=1 or FRAME_CONTROL_TELEMETRY=0 blocks automatic telemetry, not reports or contact changes you deliberately send.

Other app connections

Frame Control connects to your headset and to services used by the features you choose, including GitHub for releases, Steam, F-Droid and Flathub for listings or downloads, and the sources of apps you choose to install. It does not require a Frame Control account. The desktop app checks GitHub for updates after startup and every six hours; those requests carry no installation ID. Set FRAME_CONTROL_NO_UPDATE_CHECK=1 to stop them.

The website feedback form

What you type becomes a public GitHub issue on saphid/frame-control, including any username and diagnostic details you provide. Do not include passwords, tokens or private information. To stop abuse, the form keeps a token-salted, one-way hash of your IP address in an hourly counter for up to 65 minutes, plus a non-identifying daily counter for up to 25 hours. The form does not store or publish the raw address; Cloudflare still processes network requests.

This website

Hosted on Cloudflare Pages. The site itself sets no cookies and includes no analytics or tracking scripts. Cloudflare processes requests to serve and protect it. The download section asks GitHub for the latest release. Donations go through Ko-fi, under Ko-fi's own privacy policy.
